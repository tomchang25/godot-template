# AI Prompt Packs

Small prompt skeletons for repeatable content-generation tasks. Keep prompts generic in the base; project-specific voice, themes, naming, and gameplay context belong in the project or preset overlay.

## Packs

- `sfx_placeholder.md`: generate deterministic placeholder SFX YAML.
- `localization_block.md`: generate localized strings for one localization block.
- `yaml_content.md`: generate designer-authored YAML for a registered data entity type.
